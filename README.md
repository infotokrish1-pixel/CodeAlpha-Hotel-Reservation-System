# CodeAlpha - Hotel Reservation System

## 📋 Project Description
This is a console-based Java application built to manage hotel room inventories, handle guest reservations, process cancellations, and maintain live data tracking over application restarts using local file system persistence.

## ✨ Core Features
* **Categorized Vacancies:** Tracks room configurations across Standard, Deluxe, and Premium Suite structures.
* **Reservation Workflow:** Enables immediate customer queries, automated rate breakdowns, and simulated payment gateways.
* **Persistent Transactions:** Secures active database status records via automated local flat file input/output streams.

## 🛠️ Tech Stack
* **Language:** Java (JDK 17+)
* **Concepts:** Object-Oriented Programming (OOP), Java Collections, File I/O Streams, Exception Handling.
